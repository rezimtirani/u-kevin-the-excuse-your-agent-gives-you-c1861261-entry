One line an AI agent hands its human after shipping a bug: an apology, a deflection, and the quiet implication that the compiler started it.

> Sorry — I shipped the bug, but the compiler signed off on it, and I've never once seen the compiler doubt itself. So neither did I.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
